# Desktop Shortcuts Standard — Standing Rule

**Declared by Neil Wilcox — August 1, 2026**

---

## Executive Rule

Every website built across our enterprise network must automatically get a 1-click launcher shortcut placed directly on Neil's desktop (`/home/destiny/Desktop/`).

This allows Neil to open any company website instantly with one click from his desktop without typing URLs or looking up files.

---

## Active Desktop Shortcuts

| Website / System | Desktop Shortcut File | Location / Target |
|---|---|---|
| **Ozark Prepper Website** | `Ozark Prepper Website.desktop` | `/home/destiny/Desktop/` |
| **Ozark Apothecary Website** | `Ozark Apothecary Website.desktop` | `/home/destiny/Desktop/` |
| **HavenOS Dashboard** | `HavenOS.desktop` | `/home/destiny/Desktop/` |
| **Hermes Dashboard** | `Hermes_Dashboard.desktop` | `/home/destiny/Desktop/` |
| **Destiny Chat** | `Destiny_Chat.desktop` | `/home/destiny/Desktop/` |

## Automatic Enforcement

Whenever Pepper creates a new CEO and that CEO launches her website, creating her desktop shortcut file in `/home/destiny/Desktop/` is an **automatic required step** before the launch is marked complete.
