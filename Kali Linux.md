# Kali Linux VM

The local penetration testing and security research environment running in VirtualBox, overseen by [[Sentinel]].

## 🖥️ VM Specifications
* **VM Name:** `kali-linux-2026.1-virtualbox-amd64`
* **Status:** Running (Headless)
* **Default Credentials:**
  * **Username:** `kali`
  * **Password:** `kali`

## ⚙️ Control Commands (Linux Mint Host)
* **Start VM (Headless):**
  `vboxmanage startvm "kali-linux-2026.1-virtualbox-amd64" --type headless`
* **Stop VM (Graceful):**
  `vboxmanage controlvm "kali-linux-2026.1-virtualbox-amd64" acpipowerbutton`
* **Force Stop VM:**
  `vboxmanage controlvm "kali-linux-2026.1-virtualbox-amd64" poweroff`
* **Check Status:**
  `vboxmanage list runningvms`
