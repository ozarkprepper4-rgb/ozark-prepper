# Obsidian

The local, markdown-based knowledge base acting as [[Destiny]]'s "second brain" and memory store.

## 🧠 Role in HavenOS
* **The Galaxy Graph:** Keeps every plan, inventory item, radio frequency, and health parameter linked bidirectionally to build an interactive, visual Graph View.
* **Synchronization:** Co-designed with [[HavenOS]] to allow editing notes either through the official Obsidian desktop application or the local Web Dashboard on Port 8000.
* **FOSS & Cleanliness:** Fully offline, text-based, and immune to software rot or database lockouts.
