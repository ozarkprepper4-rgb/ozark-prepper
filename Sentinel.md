# Sentinel

The dedicated Security and System Monitoring Agent operating within [[HavenOS]].

## 🛡️ Profile & Role
* **Agent Name:** Sentinel (sub-agent of [[Destiny]])
* **Core Directive:** Protect Neil's home lab hardware, RAID filesystems, and local network servers 24/7. Focus on system longevity and proactive defense.
* **Model Base:** Optimized for fast, accurate parsing of security logs and system metrics (utilizes local [[Ollama]] models).

## 📊 Vitals Monitored (24/7)
1. **Drive Integrity & RAID Status:** Scans disks for block errors or degradation to alert Neil *before* physical drive failure occurs.
2. **Resource Allocation:** Monitors CPU load, RAM utilization, and GPU temps on Linux Mint to ensure optimal local model inference.
3. **Storage Budgets:** Checks free capacity across server partitions to prevent disk-full crashes.
4. **Security Audits:** Reviews server ports (e.g., locking down port 8000 and port 11434 to local network boundaries) and detects anomalous ingress attempts.

## ⚙️ Offline Integration
Sentinel connects directly to the `/api/system` endpoint in [[HavenOS]] to pull real-time JSON metrics of the host system.
