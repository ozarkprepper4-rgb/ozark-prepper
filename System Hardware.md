# System Hardware & Storage Architecture

## Physical Hardware Specs
* **Operating System Disk:** 1TB SSD (For OS, system packages, virtual environments, and high-speed local AI execution).
* **Storage Disk:** 1TB Hard Drive (HDD) (For larger files, video archives, models, backups, and long-term offline data storage).

## Storage & Resource Guidelines
* **Disk Space Management:** Be extremely conscious of disk space before downloading or saving files.
* **Large File Strategy:** Always save larger files and long-term media/backups directly to the 1TB Hard Drive.
* **Obsidian Memory Optimization:** Store important notes, system configurations, and essential texts in Obsidian to save system memory.
* **Review Downloads:** Periodically verify and audit downloads to ensure the 1TB OS SSD does not fill up.
