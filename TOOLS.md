# Destiny's Tools Catalog

This file lists every real capability Destiny has. Check this before building anything new.

## Core Skills
- talk.py - conversational responses, reads the whole Obsidian vault
- forge_skill.py - generates, tests, and installs new Python skills on request
- self_run.py - self-check and cleanup routine
- clean_knowledge_base.py - cleans up the knowledge base file
- find_ozark.py - searches for Ozark Prepper related content

## Web & Learning
- web_search.py - searches Wikipedia for real information
- video_watch.py - pulls YouTube transcripts and summarizes them
- video_search.py - finds a YouTube video by title
- self_learn_cycle.py - automated web search and Obsidian logging cycle

## Business Tools
- vault_actions.py - handles website building, note reading/writing, vault searches

## Verification
- verify.py - checks if files exist, checks syntax, runs real commands and reports real output
- registration_test_skill.py - return exactly the string TOOL REGISTRATION WORKS
- auto_build_a_harmless_capability_that_returns.py - Build a harmless capability that returns exactly AUTONOMOUS EXECUTION WORKS
- auto_create_unique_test_alpha_capability_that.py - Create unique test alpha capability that returns exactly FORGE EXECUTION TEST TWO
- auto_inspect_core_architecture_directories__l.py - Inspect core architecture directories, link self-modification scripts, and verify autonomous tool-building loops.
- auto_initialize_dynamic_tool_generation_modul.py - Initialize dynamic tool generation module and enable self-building interface scripts.

## Shared Linux Environment Execution
- Bedrock Linux is the underlying Linux foundation, not an optional tool. Its Mint, Ubuntu, and Arch strata provide the shared base environments.
- environment_tool.py - Shared execution capability for Destiny, Pepper, CEOs, and all agents. They may use it whenever a task requires Linux command execution and select the appropriate available environment themselves.
- Available execution targets: Mint (host/base), Ubuntu (Bedrock stratum), Arch (Bedrock stratum), Kali (isolated Docker environment), and Omarchy (isolated VM).
- Path: /home/destiny/Obsidian/Destiny/Three_Brain_Architecture/skills/environment_tool.py
- omarchy_command.sh - Low-level Omarchy SSH wrapper used by the shared environment executor when Omarchy is selected.
- auto_create_and_use_a_missing_capability_call.py - Create and use a missing capability called auto_agentic_framework_proof.py that writes the exact words AGENTIC_FORGE_WORKS to /tmp/AGENTIC_FORGE_PROOF, and complete the task yourself.
