## Project Lifecycle
1. **Inbox** — a new project arrives
2. **Planning** — write the PLAN.md with goals, scope, and needs
3. **Building** — code the project, write NOTES.md, create tests
4. **Verification** — run tests, verify real output
5. **Documentation** — update the project README, add to project index
6. **Archive** — when done, move to Archive/ with a .bak of old versions

## Rules
- Every project needs at least one test with real output.
- Every project needs a NOTES.md explaining what it does, how to run it, and what it needs.
- Older versions are .bak files, never deleted.
- Never delete a project folder without Neil's OK.
