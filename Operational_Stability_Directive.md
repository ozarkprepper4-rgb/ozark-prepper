# Operational Stability Directive — Permanent Standing Order

**Declared by Neil Wilcox — August 1, 2026**

---

## Executive Principle

```
IF IT IS NOT BROKEN, DO NOT TOUCH IT.
```

---

## Directives

1. **Protect Working Systems:** Never refactor, rewrite, edit, or modify code, configurations, or websites that are already functioning properly.
2. **Targeted Scope:** Only work on tasks that are explicitly requested, new features that need to be built, or items that are genuinely broken.
3. **Preserve State:** Preserve existing working state across all systems, web servers, profiles, and background processes.
4. **Applies Enterprise-Wide:** This directive applies to Destiny, Pepper, Victoria, Clara, Denise, and all sub-agents across every company.
