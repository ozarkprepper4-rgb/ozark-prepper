# Ollama

The local, open-source AI inference engine powering all cognitive functions inside [[HavenOS]].

## 🚀 Core Features
* **Offline-First:** Runs 100% locally on Neil's home server without sending prompt data to external cloud services.
* **Port Address:** Reachable locally at `http://127.0.0.1:11434`.
* **Central Model:** `qwen2.5:14b` and `hermes3:latest`.

## 🤖 Model Deployments
Ollama powers the specialized personas coordinated by [[Destiny]]:
* **[[Sentinel]]**: Analyzes system resources and firewall events.
* **[[Provident]]**: Evaluates pantry logistics.
* **[[Sustenance]]**: Calculates solar engineering variables.
* **[[Comms]]**: Optimizes RF protocols and antenna lengths.
